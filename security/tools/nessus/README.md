## Overview  
This project demonstrates the deployment and use of **Tenable Nessus** for vulnerability scanning, assessment, and reporting in a controlled lab environment. It highlights my hands-on skills in vulnerability management, risk prioritization, and security reporting.  
  
## Objectives  
- Deploy Nessus Professional in a lab environment.
- Scan target systems for vulnerabilities.  
- Analyze findings and prioritize remediation.  
- Generate actionable reports.

## Skills Demonstrated  
- Vulnerability scanning with Nessus.  
- Risk assessment and CVSS scoring.  
- Lab setup and system provisioning.  
- Reporting and remediation guidance.  

## Lab Environment  
- Nessus Professional installed on a Red Hat Enterprise Linux (RHEL) 8.10 VM.
- Target VMs: Windows 10 client.

## Key Outcomes  
- Successfully deployed Nessus and completed scans of multiple target systems. 
- Identified vulnerabilities and prioritized remediation steps based on CVSS.  
- Generated clear, actionable reports suitable for technical and managerial stakeholders.  
- Learned best practices for scanning in isolated and production-like environments.  
  
## Lessons Learned  
- Handling false positives and tuning scan policies.  
- Managing scan schedules and credentials securely. 
- Interpreting CVSS scores and translating technical findings to actionable remediation.
