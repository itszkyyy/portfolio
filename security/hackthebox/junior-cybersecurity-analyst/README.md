## About
The Junior SOC pathway provided by HackTheBox is part of their HTB Academy offerings. While I have a solid foundation, I've decided to embark on this course to sharpen up my skills while keeping currency on others. 
This pathway covers Cybersecurity fundamentals, Windows fundamentals, Linux fundamentals, penetration testing fundamentals, Incident-Response workflows, and security monitoring and SIEM fundamentals. 
Together, these skills aim to teach the core fundamentals of a Security Analyst, preparing them for their future career.
