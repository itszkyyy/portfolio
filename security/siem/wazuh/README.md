# About
This project is follows the installation of  Wazuh, an open-source SIEM solution, on Red Hat Enterprise Linux so I may have a security dashboard to have an overview of my network environment and my endpoints. Logging allows me to be aware of security or availability issues that may arise so I may promptly remediate the issue. Wazuh's solution provides a means to assessing an endpoint's configuration, perform file integrity monitoring, and perform active defense measures.

# Conclusion
In the modern day digital world, it is imperative that we have insight on how and what our endpoints are doing. Installing, configuring, and monitoring a SIEM solution provides insight into what traffic flows to and from your network, what occurs on your endpoints, and what file changes happen, supporting investigation efforts during or post a security event.
