## About
Global Protect is a proprietary Virtual Private Network (VPN) application developed by Palo Alto, utilizing a corporation's Palo Alto edge firewall to act as a Portal and/or Gateway.
- Portals are where end-users can connect to which they can perform actions such as authentication and downloading Global Protect configuration files.
- Gateways are where the application will connect, there can be multiple gateways for a given corporation. 
Should be noted that a single firewall can act as both the portal and gateway.

## Requirements
Global Protect requires that you have a Palo Alto Next Generation Firewall (NGFW) with the appropriate licenses for your requirement. Though the mimimum for this implementation is the Global Protect license they provide.
